## Installation & Setup

### Quick Setup (7 minutes)
```
1. Get Spotify Client ID (2 min)
   - Visit developer.spotify.com/dashboard
   - Create app and copy Client ID

2. Configure App (1 min)
   - Create .env.local
   - Add NEXT_PUBLIC_SPOTIFY_CLIENT_ID
   - Add NEXT_PUBLIC_SPOTIFY_REDIRECT_URI

3. Run & Test (1 min + 3 min)
   - npm run dev
   - Click Connect button
   - Authorize Spotify
```
